## Summary

`gh-plan` is a TypeScript ESM package for **planning**, not applying, GitHub repository changes. It interprets typed desired-state documents, reads GitHub REST state, resolves identities, computes a semantic diff and emits deterministic, dependency-ordered mutation requests. It never performs GitHub writes. The package remains private pending a separate release decision.

## Pipeline

1. [Desired-state graph](/concepts/desired-state-graph.md): normalize authoring shorthands, nested issues and relationships.
2. [Logical IDs](/concepts/logical-id.md) and [identity resolution](/concepts/identity-resolution.md): determine whether managed resources exist, are new or are ambiguous.
3. [Management modes](/concepts/management-modes.md): distinguish planner-owned changes from existing reference-only endpoints.
4. [Relationships](/concepts/relationships.md): reconcile native parent, blocked-by and related-to edges.
5. [Plans and steps](/concepts/plan-and-steps.md): compile a read-only request DAG; [late-binding refs](/concepts/late-binding-refs.md) defer post-create IDs.
6. [Diagnostics](/concepts/diagnostics.md): report unsafe, unsupported or ambiguous situations before any executor is allowed to write.
