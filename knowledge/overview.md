## Summary

`gh-plan` is a TypeScript ESM package for **planning**, not applying, GitHub repository changes. It interprets typed desired-state documents, reads GitHub REST state, resolves identities, computes a semantic diff and emits deterministic, dependency-ordered mutation requests. Its public entrypoint never performs GitHub writes. The internal M8 staging primitive supports injected dispatch, pre/post-write verification, exact-marker interrupted-issue-create recovery and secret-free appendable outcome logs. M8.1.5 adds end-to-end synthetic repeat-run and lost-response recovery fixtures. The primitive remains unexported. The [A1 GitHub-native cooperative ownership policy](/decisions/github-native-apply-ownership.md) now has an **internal CAS primitive** and an independently validated, **operator-only manual abandoned-lock recovery runbook**. Both have disposable private-repository CAS evidence; there is still no public executor, automatic recovery or expired-lock takeover. Internal [B1 typed preflight and normalized intent](/decisions/progressive-apply-postconditions.md) are implemented, along with **GET-only milestone and issue verifiers** checking full open/closed catalogs, stable identities, changed fields and interrupted-create recovery. The [internal GitHub reference adapter](https://github.com/attention-spa/gh-plan/blob/main/docs/github-reference-adapter.md) now composes A1 CAS and B1 readback with the C2 callback lifecycle, but has only synthetic full-stack validation and **direct private-repo GitHub API smoke**, not a live end-to-end run of the adapter. [#181](https://github.com/attention-spa/gh-plan/issues/181) remains the full live verification gate, and the [C2 public runtime API](/decisions/caller-injected-apply-contract.md) remains unexported. C2 deliberately trusts caller-injected dispatch/verification and therefore does not itself guarantee real GitHub-backed safety. The package remains private pending a separate release decision.
The [C2 callback application contract](/decisions/caller-injected-apply-contract.md) now has named public types and a sanitized error class, plus an internal **pure full-plan B1 preflight** gate. The internal #188 C2 lifecycle now executes dependency-ordered, owner-guarded, typed-readback-verified synthetic callback sequences with append-only safe audit and abort/release handling. There is **no public executable applyPlan()**, GitHub resource writer, or guarantee of truthful caller-supplied read/ownership callbacks; #181 live acceptance and #190 public export remain separately gated.

## Pipeline

1. [Desired-state graph](/concepts/desired-state-graph.md): normalize authoring shorthands, nested issues and relationships.
2. [Logical IDs](/concepts/logical-id.md) and [identity resolution](/concepts/identity-resolution.md): determine whether managed resources exist, are new or are ambiguous.
3. [Management modes](/concepts/management-modes.md): distinguish planner-owned changes from existing reference-only endpoints.
4. [Relationships](/concepts/relationships.md): reconcile native parent, blocked-by and related-to edges.
5. [Plans and steps](/concepts/plan-and-steps.md): compile a read-only request DAG; [late-binding refs](/concepts/late-binding-refs.md) defer post-create IDs.
6. [Diagnostics](/concepts/diagnostics.md): report unsafe, unsupported or ambiguous situations before any executor is allowed to write.
