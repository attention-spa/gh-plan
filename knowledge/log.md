# Knowledge Update Log

## 2026-11-16

- **M8.1.2 fresh postcondition reads and skips ([#128](https://github.com/attention-spa/gh-plan/issues/128), [PR #159](https://github.com/attention-spa/gh-plan/pull/159))**: Internal execution now requires an injected authoritative live postcondition read before every step, skips satisfied mutations, records skipped IDs, and reuses validated observed identities for skipped create producers. Invalid or missing read results fail closed. Added synthetic read-order, mixed-skip, all-skip, malformed-read, late-binding and read-failure fixtures. The reader must be supplied by the caller and is not shipped; post-write verification, recovery and public `applyPlan()` remain deferred.

- **M8.1.1 execution-order staging ([#127](https://github.com/attention-spa/gh-plan/issues/127), parent [#37](https://github.com/attention-spa/gh-plan/issues/37))**: Added an internal, injection-only execution primitive that validates the full planned-request DAG before writes, executes dependencies first, and late-binds validated create response identities. Added synthetic dispatch/blocked/missing-reference/cycle tests. It is deliberately excluded from the package entrypoint: postcondition reads, interruption recovery, verification and idempotent public `applyPlan()` remain separate M8 tasks.

- **M7.4 orphan and duplicate safety policy ([#36](https://github.com/attention-spa/gh-plan/issues/36))**: Added report-only [prune authoring](/schema/prune-duplicates.md) with informational marker-orphan/title-collision diagnostics, a [pure guarded lifecycle compiler](/api/compilePruneSteps.md), opt-in reversible issue closure and canonical duplicate comments. GraphQL-only permanent deletion proposals require `mode:"graphql"`, `prune:"close"`, `deleteDuplicates:true`, verified duplicate/canonical identity and a prior durable reason. REST deletion and all other GraphQL modes block; discovery remains GET-only and no executor exists. Updated [issue deletion policy](/decisions/issue-deletion-policy.md), tests, public API/schema and REST mappings without implementing an executor.

- **M7.3 milestone due date ([#35](https://github.com/attention-spa/gh-plan/issues/35))**: Added [milestone `due_on` authoring](/schema/milestone.md) with Gregorian `YYYY-MM-DD` validation, nullable REST timestamp discovery, UTC-calendar-date [semantic comparisons](/api/diffGithubState.md), and date set/clear/noop [POST/PATCH compilation](/api/compileMilestoneSteps.md). Added synthetic tests for creation, updates, removal, omission, invalid dates, missing observations and read-only discovery; regenerated JSON Schema and updated REST/API contract documentation.
- **M7.2 Projects v2 item planning ([#34](https://github.com/attention-spa/gh-plan/issues/34))**: Added [existing board references and per-issue/PR field maps](/schema/projects-v2.md), read-only REST discovery of boards, fields and repository-scoped items, and the [pure membership/field compiler](/api/compileProjectItemSteps.md). Only text/number/date/single-select/iteration fields are reconciled; project/field creation is explicitly unsupported. Added synthetic fixtures, typed authoring JSON Schema, API/REST permission references and DAG late binding.
