# Schema Elements

- [Repository schema element](/schema/repository.md) — Target repository selector and the scope of all desired GitHub resources.
- [Issue schema element](/schema/issue.md) — Managed and reference-only issues, nested children, named fields, labels, assignees and identity hints.
- [Pull request schema element](/schema/pull-request.md) — Managed same-repository pull requests keyed by an open head/base pair, with named reviewers and safe Closes references.
- [Milestone schema element](/schema/milestone.md) — Managed milestones with partial title/description/state and reference-only milestone identities.
- [Label schema element](/schema/label.md) — Repository label creation and metadata updates by name, plus issue label assignments.
- [Relationship schema element](/schema/relationship.md) — Directional parent and blocker edges and symmetric GitHub related-to associations.
- [Set and remove operations](/schema/set-remove-operations.md) — Shorthand values, explicit sets, removal operators and omitted-property reconciliation semantics.
